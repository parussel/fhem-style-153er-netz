# Asset provenance

## 153er branding

- `www/153er-netz/images/153er_netz.png`: logo for this edition with the fish, cross and net motif and domain typography. It is not an official source logo.
- `www/153er-netz/images/bg_wrapper.jpg`: background created for this edition.

## Upstream functional icons

`www/images/153er_netz/favicon.ico` is the edition's custom multi-resolution favicon, cropped from the matching logo. `assets/153er-netz-favicon-source.svg` is the editable vector source for the motif.

All other files under `www/images/153er_netz/` are unchanged functional Smart Home icons inherited from the MIT-licensed upstream repository. The upstream README credits the Smart House Icon Set Free published on Dribbble.

## Upstream code

Theme code is derived from `klein0r/fhem-style-haus-automatisierung`, branch `version-2`, release 2.19. The original MIT notice is preserved in `LICENSE`.
