# Asset provenance

## 153er branding

- `www/153er-netz/images/153er_netz.png`: concept logo for this edition based on the approved fish/cross/net composition and domain typography. The 2026-10-17 refinement makes the fish body lighter and gives the net slightly more separation. This is a project concept asset, not an official source logo.
- `www/153er-netz/images/bg_wrapper.jpg`: generated specifically for this edition on 2026-10-16; dark navy network background with muted gold nodes.

## Upstream functional icons

`www/images/153er_netz/favicon.ico` is the edition's custom multi-resolution favicon, cropped from the matching fish/cross/net concept logo. `assets/153er-netz-favicon-source.svg` is retained as an editable vector reference for the motif. Version 1.0.4 refreshes the icon to match the refined layout logo.

All other files under `www/images/153er_netz/` are unchanged functional Smart Home icons inherited from the MIT-licensed upstream repository. The upstream README credits the Smart House Icon Set Free published on Dribbble.

## Upstream code

Theme code is derived from `klein0r/fhem-style-haus-automatisierung`, branch `version-2`, release 2.19. The original MIT notice is preserved in `LICENSE`.
