# FHEM Style – 153er Netz Edition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an independently installable 153er-netz.de edition of Kleinor's FHEM theme without changing its layout or behavior.

**Architecture:** Fork version 2.19 into a distinct `153er_netz` runtime namespace. Keep the upstream SCSS structure and JavaScript behavior, replace only branding and primary accents, and package all owned files through a separate FHEM control manifest.

**Tech Stack:** SCSS/CSS, JavaScript/jQuery, SVG/PNG/JPEG assets, FHEM update control files, PowerShell/bash validation scripts.

**Spec:** `docs/superpowers/specs/2026-10-16-153er-netz-theme-design.md`

## Global Constraints

- Preserve every upstream layout dimension, spacing rule, selector behavior, and JavaScript interaction.
- Base all work on upstream version 2.19 commit `508f7b8dcc6450ed7939e20de980fbb3c4aedc09`.
- Use only the `153er_netz` runtime namespace and never overwrite `hausautomatisierung_com` files.
- Treat the concept emblem as provisional until an official logo source is supplied.
- Do not touch a running FHEM installation or migration data.

## Review Focus

- Ensure no upstream layout declarations change accidentally.
- Ensure reduced-motion users receive a static background.
- Ensure the control manifest contains every runtime file and no development-only file.
- Ensure uninstall targets are limited to edition-owned paths.
- Ensure external URLs point to `parussel/fhem-style-153er-netz` and `153er-netz.de` as intended.
